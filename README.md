# SauceDemo QA Manual Testing

Projeto de estudo e portfólio em QA Manual usando a aplicação SauceDemo.

## Aplicação testada

https://www.saucedemo.com/

## Objetivo

Documentar o processo de QA Manual, incluindo workflow, histórias de usuário, plano de testes, cenários, casos de teste, execução e bugs.

## Estrutura

- `docs/`: documentação do processo de QA
- `test-cases/`: casos de teste step-by-step e BDD
- `test-execution/`: registros de execução e evidências
- `bug-reports/`: reports de bugs
