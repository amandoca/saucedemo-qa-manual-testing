# TC-001 - Login com credenciais válidas

## ID

TC-001

## Título

Login com credenciais válidas

## Pré-condição

Usuário está na tela de Login do SauceDemo.

## Dados

```text
Username: standard_user
Password: secret_sauce
```

## Passos

| Passo | Ação |
| --- | --- |
| 1 | Acessar https://www.saucedemo.com/ |
| 2 | Preencher o campo Username com standard_user |
| 3 | Preencher o campo Password com secret_sauce |
| 4 | Clicar no botão Login |

## Resultado esperado

Sistema deve direcionar o usuário para a tela Products e exibir a lista de produtos.

## Resultado obtido

Usuário foi direcionado para a tela Products e a lista de produtos foi exibida.

## Status

Passed
