# TC-001 - Login com credenciais validas

## ID

TC-001

## Titulo

Login com credenciais validas

## Pre-condicao

Usuario esta na tela de Login do SauceDemo.

## Dados

```text
Username: standard_user
Password: secret_sauce
```

## Passos

| Passo | Acao |
| --- | --- |
| 1 | Acessar https://www.saucedemo.com/ |
| 2 | Preencher o campo Username com standard_user |
| 3 | Preencher o campo Password com secret_sauce |
| 4 | Clicar no botao Login |

## Resultado esperado

Sistema deve direcionar o usuario para a tela Products e exibir a lista de produtos.

## Resultado obtido

Usuario foi direcionado para a tela Products e a lista de produtos foi exibida.

## Status

Passed
