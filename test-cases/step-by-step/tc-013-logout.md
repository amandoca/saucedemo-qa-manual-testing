# TC-013 - Realizar logout pelo menu lateral

## ID

TC-013

## Título

Realizar logout pelo menu lateral

## Pré-condição

Usuário está logado na tela Products.

## Dados

```text
Username: standard_user
Password: secret_sauce
```

## Passos

| Passo | Ação |
| --- | --- |
| 1 | Acessar https://www.saucedemo.com/ |
| 2 | Fazer login com standard_user e secret_sauce |
| 3 | Na tela Products, clicar no menu lateral |
| 4 | Clicar em Logout |

## Resultado esperado

Sistema deve retornar para a tela de Login, exibindo os campos Username e Password e o botão Login.

## Resultado obtido

Sistema retornou para a tela de Login, exibindo os campos Username e Password e o botão Login.

## Status

Passed
